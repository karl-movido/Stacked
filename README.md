# Stacked

A simple browser-based book library app for tracking your reading list. Add books, update reading progress, mark favorites, and filter your shelf by status.

## Features

- Add new books with title, author, total pages, status, and pages read
- Edit existing book details
- Update progress directly from each book card
- Mark books as favorites using pinning
- Toggle reading status between To read, Reading, and Done
- Filter books by All, Favorites, Reading, To read, or Done
- Search books by title or author
- Data saved to browser's localStorage

## Files

- `index.html` — project structure and UI layout
- `style.css` — styling for the app interface
- `script.js` — app logic, book handling, filters, and local storage

## Usage

1. Open `index.html` in a web browser.
2. Click **Add a book** to open the add panel.
3. Fill in the book title, author, total pages, status, and pages read.
4. Click **Add to shelf** to save the book.
5. Use the filter tabs to view books by status or favorites.
6. Search by title or author using the search field.
7. Click the edit icon on a book card to update the book.
8. Click the page count to edit pages read directly.
